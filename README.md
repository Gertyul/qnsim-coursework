# qnsim — імітація мереж масового обслуговування з пріоритетом і блокуванням маршруту

Курсова робота з освітнього компонента «Моделювання систем. Курсова робота», завдання **B24**:
розробити універсальний алгоритм імітації мереж масового обслуговування, у якому можна
враховувати пріоритет вибору маршруту та встановлювати блокування маршруту за заданою умовою.

Алгоритм імітації власний, без бібліотек імітації (SimPy тощо): час просувається до найближчої
події, модель — за подіями, статистика збирається на інтервалах між подіями.

## Можливості

* Елементи: `Create` (надходження), `Process` (СМО з m каналами і чергою FIFO / LIFO / за
  пріоритетом вимоги, обмеженою або необмеженою), `Dispose` (вихід).
* Розгалуження на довільну кількість гілок; кожен маршрут `Route` може мати **пріоритет** (число),
  **ймовірність** вибору серед маршрутів однакового пріоритету, **умову блокування** та
  **числовий параметр** (групування `group=k` або розгрупування `split=k`).
* Умови блокування записуються **логіко-алгебраїчними виразами** від стану елементів і часу:
  функції `L(X)`, `K(X)`, `Z(X)`, `Y(X)`, `N(X)`, `F(X)`, `M(X)`, `MAX(X)`, змінна `t`,
  операції `+ − · / mod`, `= ≠ < ≤ > ≥`, `∈ [a; b)`, `∧ ∨ ¬` (або `and or not`).
  Вирази розбираються власним синтаксичним аналізатором, помилки виявляються до початку імітації.
* Для часових умов (`t mod 480 ∈ [450; 480)`) моменти зміни значення обчислюються точно.
* Блокування каналу СМО (стан 2): вимога утримується в каналі, доки маршрут не відкриється;
  каскадне розблокування в порядку часу блокування; призупинення або втрата надходження.
* Відкидання перехідного періоду, спостерігач, протокол подій, хук `on_choice` для аудиту рішень.

## Приклад

```python
from qnsim import Model, Create, Process, Dispose, Exp

src = Create("Надходження", Exp(2.0))
m1  = Process("M1", Exp(1.4))
fa  = Process("FA", Exp(2.5), max_queue=2)
fb  = Process("FB", Exp(4.0), max_queue=2)
fr  = Process("FR", Exp(6.0))
out = Dispose("Вихід")

src.to(m1)
m1.add_route(fa, priority=3, block="L(FA) = KA ∧ K(FA) ≠ 0")
m1.add_route(fb, priority=2, block="(L(FB) = KB ∧ K(FB) ≠ 0) ∨ t mod 480 ∈ [450; 480)")
m1.add_route(fr, priority=1)            # гілка лише з пріоритетом
for x in (fa, fb, fr):
    x.to(out)

model = Model(src, m1, fa, fb, fr, out, seed=1, params={"KA": 2, "KB": 2})
print(model.report(model.simulate(20000, warmup=2000)))
```

## Структура

| Файл | Призначення |
|---|---|
| `qnsim/distributions.py` | генератори exp, unif, norm, erl, const |
| `qnsim/conditions.py` | мова умов блокування: розбір, обчислення, моменти зміни |
| `qnsim/elements.py` | Create, Process, Dispose, Route, Job |
| `qnsim/model.py` | алгоритм імітації |
| `examples/demo_line.py` | демонстраційна мережа ділянки механообробки |
| `examples/robots_conveyor.py` | приклад із посібника (роботи вздовж конвеєра) |
| `verification.py` | верифікація: порівняння з аналітичними моделями, таблиця, протокол |
| `experiments.py` | експериментальне дослідження (Е1–Е7) |
| `proposals.py` | оцінка запропонованих змін |
| `plots.py` | графіки |
| `schemes.py` | схеми в нотації посібника (формалізована модель, блок-схеми, позначення) |
| `tests/` | модульні тести (`python -m pytest tests`) |
